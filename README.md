# MetaTaken™

**We have a particular set of tools. We find it. We remove it.**

MetaTaken is a local Windows utility for inspecting, removing and verifying metadata from image files while preserving image quality wherever possible.

**Status:** In development  
**Platform:** Windows  
**Processing:** Local only — no uploads, accounts or telemetry.

MetaTaken is designed around a simple workflow:

**Inspect → Clean → Verify**

Initial support is focused on JPEG, PNG and WebP images, including privacy metadata and AI-related provenance metadata where supported.
