Local / offline metadata cleaning

Remove image metadata locally on Windows — no image upload required.

MetaTaken is a desktop utility, not an image-cleaning website. The inspection, cleaning and verification workflow runs on your PC, so your images do not need to be sent to a MetaTaken processing server.

Privacy without a server-retention promise.

Online metadata tools are not all the same. Some upload files to a server; some process files entirely inside the browser. MetaTaken takes a different route: it is a local Windows application whose image-processing workflow runs on your computer.

That removes one whole category of privacy assumption. You do not have to trust a MetaTaken image-processing server not to retain your file, because there is no MetaTaken cloud image-processing service in the workflow.

What “local” means in MetaTaken

No image uploadsInspection, cleaning and verification are performed on the local PC.
No accountThere is no sign-in requirement before you can clean your own images.
No application telemetryThe app is designed without behavioural tracking or analytics.
Bundled metadata engineExifTool is bundled locally as the primary metadata engine.

Local processing is only useful if the result is trustworthy.

MetaTaken does more than strip metadata. It inspects first, lets you choose Privacy Clean or Full Metadata Clean, writes a separate copy, then automatically inspects that copy again.

Where supported, it also compares decoded image pixels before and after. That means “local” is paired with evidence about what was actually removed and whether protected image content stayed unchanged.

When a local desktop cleaner is a good fit

  • You do not want personal, client or unpublished images uploaded to another image-processing service.
  • You are cleaning many files and want folders, subfolders or batches instead of one-at-a-time uploads.
  • You want to inspect metadata before deleting it rather than blindly re-encoding the picture.
  • You want post-clean verification and a clear Review state when something cannot be safely handled.
  • You want AI provenance, ordinary privacy metadata and raw Advanced metadata in one workflow.

Still verify where you download the app from.

“Local” does not mean “trust nothing”. Download MetaTaken from the official MetaTaken GitHub release, review the published release information and checksum, and keep the original file until you are satisfied with the cleaned output.
