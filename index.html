The MetaTaken workflow

Four steps. That's it.

Power underneath, simplicity above. MetaTaken keeps the main workflow deliberately small.

01

Drop

Add individual images, multiple folders, subfolders or a batch.

02

Inspect

See findings grouped into understandable categories, with detailed analysis available when you want it.

03

Clean

Use Privacy Clean or Full Metadata Clean. MetaTaken creates a separate cleaned copy.

04

Verify

The cleaned output is inspected again, with decoded-pixel comparison where supported.

LOOK

  • Plain-language categories
  • Detailed analysis available
  • No file modification
PRIVATE

Privacy Clean

Target personal and private metadata while preserving the image workflow.

  • Location and GPS
  • Author, device and timestamps
  • Separate cleaned copy
FULL

Remove safely removable metadata more broadly, including supported provenance information.

  • EXIF, XMP and IPTC
  • Supported C2PA / JUMBF data
  • Automatic post-clean verification

Conservative by design

MetaTaken doesn't pretend.

Some image structures are unusual, proprietary or too risky to rewrite blindly. When the evidence isn't strong enough, MetaTaken says so.

That means a file can be marked Review instead of being called clean when something remains, is uncertain, or cannot be safely verified.

✓
CleanRequested cleaning and verification passed.
—
No changes neededNothing targeted by the selected mode needed removal.
!
ReviewSomething remains, is uncertain or needs attention.
×
FailedThe requested operation or required verification did not complete.

Verification is part of the job

Cleaning isn't finished until it's checked.

After cleaning, MetaTaken automatically re-inspects the output, reports what was removed or retained, and compares decoded image pixels where supported.

✓ Original preserved ✓ Output re-inspected ✓ Pixel content checked where supported

A useful distinction

Metadata isn't the same as a watermark.

MetaTaken cleans supported metadata and provenance structures. It does not claim to remove pixel-level watermarks.

Quick answers

FAQ

Does MetaTaken upload my images?

No. The desktop image-processing workflow is designed to inspect, clean and verify supported images locally on your computer, with no cloud image-processing path.

Does MetaTaken overwrite my originals?

No. MetaTaken never cleans an image in place or overwrites your original. Cleaning creates a separate output copy, and an existing cleaned output is not silently overwritten.

Does MetaTaken remove AI metadata?

Full Metadata Clean targets safely removable metadata broadly, including supported C2PA / Content Credentials / JUMBF provenance structures. The result is then inspected again.

Does MetaTaken remove SynthID?

No claim is made about removing pixel-level watermarking such as SynthID. Current SynthID status is: Not tested / detection unavailable.

Does “Clean” mean my image is guaranteed anonymous?

No. MetaTaken reports what it can detect, remove and verify. It deliberately uses Review, Failed, Unsupported or uncertain outcomes when stronger claims are not justified.

Why would a file show Review?

Review means something remains, is uncertain, is structurally protected, or could not be safely handled or verified. MetaTaken prefers that over a false Clean result.

Is MetaTaken free?

Yes. MetaTaken for Windows is proprietary freeware: free to download and use.
